## Before publishing
Update `index.html` with the correct event names, timings, venue, family details and RSVP information. In `script.js`, replace the empty `rsvpEmail` value with the email address that should receive RSVPs. The pre-wedding event date is currently set to 17 November 2026 as a placeholder; change it if needed.

The music control is a placeholder. Only add music you own or are licensed to use.

## Deploy using GitHub Pages (no local installation)
1. Open your repository on GitHub.
2. Choose **Add file → Upload files**.
3. Upload the contents of this project folder (not the ZIP file itself), preserving the `.github/workflows` folder.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **GitHub Actions** as the source.
7. Open the **Actions** tab and wait for the `Deploy wedding invitation to GitHub Pages` workflow to finish with a green check.
8. Your site will be published at `https://msmohankumar.github.io/MS-wedding/`.

## Updating the website
Edit `index.html`, `styles.css` or `script.js` directly on GitHub. Commit changes to `main`; GitHub Actions will publish the update.
